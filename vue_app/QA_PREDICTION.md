# 临床二分类预测模型工具：本地开发验收

开发验收日期：2026-11-02。以下记录为各阶段的验收快照；2026-11-03 用户已授权将第五个工具随 V3.1.0 发布，跨平台冻结引擎和安装包验收由发布流水线执行。

## 功能

- XLSX / CSV 导入、多工作表选择，编号／结局映射、阳性结局确认、变量筛选及连续／分类类型设置。
- 分层比例／指定例数划分；固定种子；LR、RF、XGB、SVM；训练折内预处理和五折 AUC 网格搜索；可编辑有限参数网格；分类阈值设置。
- 后台任务、进度与步骤间取消；错误恢复；切换科研工具后保留当前页面参数与结果。
- 同批预测概率计算性能表、ROC、H-L 分组校准、Brier；列线图使用同一次拟合的 LR。
- 650 DPI PNG、矢量 PDF、Excel、完整 ZIP，包含病例划分与逐例概率、HL 分组贡献、最优参数、配置、源数据哈希、环境版本。

## 当前边界

第一版只支持二分类结局，不支持生存分析或多分类。CSV 支持 UTF-8／GB18030。训练集每类至少五例。AUC CI 为 300 次百分位 Bootstrap；H-L 低期望频数和少于三组情况明确提示。统计结果不保证达到指定阈值。模型性能与变量合理性需要结合研究目的判断。

本机通过的是 macOS 开发预览与浏览器流程；尚未对新增工具进行 Windows 安装包或冻结引擎测试。用户试用确认后再安排跨平台打包测试与发布。
