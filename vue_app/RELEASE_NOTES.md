## V3.2.10

- 修复 360 DTFence 双向布局同步解析、匹配和空位保留。
- 优化待办灵动岛、QuickShot 截图与快捷键设置。

V3.2.9 · 修复 Windows 360 双向布局同步、macOS 截图和桌面待办小组件权限。

- 360 同步会正常暂停并恢复 360，避免运行中覆盖 Windows 位置；过滤 DTF 元数据尾记录并校验实际落位。
- 修复 macOS 截图误传 Windows 专用参数，并补充跨平台失败详情。
- 修复待办小组件动态窗口的 WebView ACL。

V3.2.8 · 完善桌面同步、截图和待办小组件。

- 新增 360 DTFence 与 Windows 桌面排列双向同步，支持匹配、忽略缺失和空白网格放置。
- 完善截图工具：区域选择、裁剪、撤销、重做、方框/圆框/文字标注、自动剪贴板复制和全局快捷键。
- 新增可开关、置顶、可拖动的桌面待办小组件。

V3.2.7 · 兼容无系统剪贴板权限的原生 UI 验证。

- 原生 UI 审计在系统剪贴板不可用时接受应用提供的手动复制提示，不影响复制内容和浏览器端剪贴板行为。

V3.2.6 · 修复发布验证中的工作空间初始化选择器。

- 修复批量选择回归测试在工作空间初始化表单中选择到文件夹按钮的问题。

V3.2.5 · 修复批量选择回归测试并重新发布统计工具。

- 修复批量选择浏览器回归测试依赖工作空间初始化的问题，发布验证可以独立运行。

V3.2.4 · 新增列联表统计和平均值对比工具。

- 新增 SPSS CROSSTABS 风格的列联表分析：行列百分比、Pearson 卡方、似然比卡方、Fisher 精确概率、Yates 校正、Bonferroni 两两比较、Kappa 和 McNemar / McNemar-Bowker 检验。
- 新增 MedCalc 风格的两独立样本平均值对比：等方差 t 检验、Welch 不等方差 t 检验、合并标准差、标准误、95% 置信区间、t 值、自由度、P 值和 Cohen’s d。
- 两个工具都支持本机计算、结果复制和 JSON 保存，并加入输入校验和专项测试。

V3.2.3 · 桌面布局恢复流程与备份分页。

- 备份列表默认每页 20 条，可选择 20、50、100 条；支持首页、上一页、下一页、末页。新增备份回到第一页，删除或自动清理后自动校正页码，避免空白页。
- “恢复 360”支持运行中发起：校验备份与进程身份，正常退出桌面助手，完整保留退出后配置作为回退副本，恢复并校验后重新打开原本运行的 360。无法正常退出时停止操作，不强杀进程、不结束 Explorer 或安全卫士服务。
- 配置恢复成功但自动启动失败时单独提示手动打开。原本未运行的 360 保持关闭；回退失败时不自动启动，以便保留现场进行手动恢复。
- 360 运行时也允许恢复 Windows 原生布局，确认框和结果明确说明不会修改 360 自己管理的布局；增加延迟坐标复核，发现位置被改回时报告失败，避免接口立即成功就误报恢复完成。
- 保留 v3.2.2 的双份备份、工具开关、诊断日志、恢复前配置回退副本，以及 Windows 后台任务状态文件访问重试。

360 是否接受正常退出、重开后布局是否生效，仍需在实际安装了 360 的 Windows 电脑测试；自保护或权限阻止正常退出时请按提示手动操作。文件校验和检测到进程启动不代表屏幕布局已人工验收。
