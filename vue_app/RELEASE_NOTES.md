V3.2.0 · 新增桌面布局备份，下载文件名标注版本。

- 第六个工具「桌面布局备份」：Windows 保存和恢复桌面图标位置，恢复前自动备份当前排列；新增图标放入空网格，已删除图标跳过，空位不足时停止恢复。
- 自动备份频率支持 1～1440 分钟，默认 15 分钟；软件运行期间按频率保存，重新打开时检查是否到期。
- 普通备份保留 1～500 份，默认 20 份；永久保留的备份不参与清理，取消保护后才可删除。
- macOS 显示「非windows电脑无法使用」，其余五个工具继续可用。
- Windows 安装版、免安装版和两种 Mac 架构的下载文件名都标明版本，今后发布自动沿用该规则。应用内更新优先下载带版本号的文件。
- 不带版本号的同内容文件仅供旧版应用自动更新兼容，手动下载请选择带 v3.2.0 的文件。

包含 V3.1.0 的临床二分类预测、可选 LASSO / SHAP 分析、全局界面缩放和小屏侧栏滚动功能。现有用户数据继续保留。

此前 V3.1.0 功能：

- 新增第五个工具“临床二分类预测”：导入 XLSX / CSV，选择结局、阳性类别和指标，支持分层训练／验证划分，以及 LR、RF、XGBoost、SVM 四模型的五折交叉验证和网格搜索。
- 输出 AUC 与置信区间、准确率、灵敏度、特异度、PPV、NPV、F1、Brier、H-L 分组结果，生成训练／验证 ROC、校准图和同一 LR 模型的列线图；支持导出 Excel、PNG、PDF 与完整分析资料。
- LASSO 筛选诊断和 SHAP 解释作为可选分析，默认关闭；不自动改变四模型输入指标。支持 SHAP 蜂群图、重要性图、单病例瀑布图及力图。
- 新增全局与分图样式设置，可调整 DPI、字体、配色、顺序、坐标和标注；样式重绘复用已计算结果。大画布自动控制 PNG 像素预算，PDF 保留矢量输出；SHAP 长标签换行并按指标数排版。
- 设置新增 70%～125% 全局界面缩放，自动保存；小屏幕侧栏可独立滚动，底部菜单可访问。
- 修复第三、第五工具的桌面文件拖入，统一侧栏与工作台工具图标。
- Windows 下临床数据导入与结果元数据统一使用 UTF-8，支持中文文件名和中文指标，不依赖系统区域编码。
- 包含未发布的 V3.0.6 修订：Word 导入自动匹配并核对、待确认行浅红提示、通知两秒后消失，以及工具二带坐标轴的数据分布图。

用户目录中的现有数据和工作空间继续保留。界面缩放不改变导出图件的尺寸或 DPI。
