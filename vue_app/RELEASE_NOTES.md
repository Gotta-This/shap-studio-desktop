V3.0.1 修复发布包数据生成失败和窄窗口侧栏问题。

- 修复桌面主程序误用开发机器 Python 脚本路径的问题，正式包改为调用随包引擎。
- 修复桌面错误信息被吞掉、生成失败却只显示“正在准备…”的问题。
- 修复窄窗口下收起侧栏后仍占 190px 空间的问题；更窄时自动显示紧凑导航。
- 修复 Mac WebKit 打开搜索框时滚动条空间重复补偿造成的页面跳动，并增加逐帧布局稳定性测试。
- 发布检查新增实际桌面主程序到 Python 引擎的完整调用测试，覆盖四项科研工具，不需要打开窗口或控制鼠标。

已有 V3.0.0 用户请下载此版本替换应用；旧版桌面桥接失败会影响应用内的更新检查。配置和稿件数据保留，Qt 数据仍可从设置迁移。

Windows 推荐 Setup.exe；有 WebView2 的环境也可使用 Portable.zip。Mac 按 CPU 选择 arm64 或 x86_64 包，解压替换应用。无需另装 Node 或 Python。个人分发包没有商业代码签名或 Apple 公证。旧版 .doc 转换需要本机 Word（Mac）或 LibreOffice，.docx 可直接读取。
