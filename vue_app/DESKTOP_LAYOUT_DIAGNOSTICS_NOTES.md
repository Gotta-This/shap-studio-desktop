Windows 桌面布局恢复诊断测试版（v3.2.2-beta.1）。正式版自动更新渠道保持 v3.2.1。

本版用于排查同机“提示恢复成功，但图标未移动或位置不对”的问题，目前尚未确认根因。

- 记录 Windows 版本类型、DisplayVersion、系统构建号、程序版本、屏幕尺寸、DPI 和网格间距。
- 记录所选备份类型与时间、匹配数量、实际需要移动数量、Windows 批量定位接口 HRESULT、每次恢复后的坐标核验。
- 文件名及完整路径不写入日志，图标通过匿名标识关联；不读取文件内容。
- 恢复结果持续显示；目标布局与当前一致时明确提示“没有需要移动的图标”。
- 第六个工具顶部新增“导出诊断日志”按钮。日志自动轮换，最多保留三段。

测试步骤：解压免安装版，先手动保存一份布局，再移动几个图标，恢复刚才的那份备份，随后点击“导出诊断日志”，将导出的 JSON 提供给开发者。请勿将“恢复前自动备份”误认为原先的目标布局。

本版沿用原有图标匹配和定位接口；未加入跨电脑匹配或未经确认的坐标转换。请先关闭正式版再运行诊断版。
