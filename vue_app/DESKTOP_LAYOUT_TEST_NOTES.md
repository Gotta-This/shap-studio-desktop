Windows x64 测试版，在 v3.1.0 基础上新增第六个工具「桌面布局备份」。

- 手动备份及恢复桌面图标位置；恢复前自动保存当前排列。
- 原有图标按备份还原，新增图标放入空网格；已删除图标跳过，空位不足时停止。
- 备份可设永久保留，不参与清理；取消保护后才能删除。
- 软件打开期间按频率自动备份，支持 1～1440 分钟，默认 15 分钟。
- 普通备份保留 1～500 份，默认 20 份；频率与份数设置持久保存。
- 重新打开时检查到期时间；切换页面不影响自动备份。

本版用于 Windows 实机验收，未替换正式版及自动更新渠道。建议先下载免安装 ZIP，解压后运行 research-studio-v3.exe。备份仅保存位置，不包含文件内容。恢复前请关闭桌面的「自动排列图标」。

包含自动化排列算法、保护清理、设置持久化及冻结引擎测试；真实桌面、多显示器及系统 DPI 下的恢复效果待实机验收。
