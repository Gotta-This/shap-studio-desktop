# 科研数据工具集

离线桌面应用，内置 Python。首页提供四个平级入口：

1. 自定义类别数列（HTML 第一个工具）。
2. 均数 / 标准差模拟数据（HTML 第二个工具）。
3. Word 一键生成 Excel。
4. 模拟数据生图（完整 Notebook 数据生成、逻辑回归和六类 SHAP 图）。

每个模块单独持有参数、后台任务、结果和保存位置。按需打开；返回首页保留本模块状态。SHAP 的配置载入、运行和重绘不会重建另外三个模块。首页没有共享的生成或保存按钮。

当前 UI 采用浅绿色主题与固定的四模块导航，生图模块使用横向流程导航。界面颜色统一位于 `clinical_studio/theme.py`，与用户设置的导出图表颜色独立。每张图的样式从左侧列表选择；DPI、导出格式、绘图种子和样本索引位于“导出格式、清晰度与样本”页签。小窗口中两组连续变量参数自动上下排列。数值工具的分布预览根据实际生成数据绘制，统计目标仍是近似匹配。

## 模拟数据生图

1. 打开 `dist/SHAP分析工作台.app`（当前构建为 Apple 芯片 Mac 版本，内置 Python，无需另行安装环境）。
2. 在首页进入“模拟数据生图”，然后在“数据参数”中配置所有特征。连续变量的阳性组和阴性组均有独立的均值、标准差、上下限；可设置向零取整、四舍五入和保留小数位数。二分类变量可设置编码及两组概率。
3. 在“模型与解释”中配置划分比例、种子、逻辑回归、决策阈值和 SHAP 背景样本数。
4. 在“图表样式”中调整公共样式。选择某张图，勾选“单独设置”可覆盖该图的每一项颜色、字体、字号、线宽、散点、尺寸等参数。“本图参数”中可开关图表、修改标题和文件名、选择依赖图展示或交互着色特征。
5. 选择保存目录并点击“生成数据并分析”。每次运行保存到独立的时间戳目录，不覆盖旧结果。
6. 查看图表大图、完整数据、模型评估、系数和逐行预测。可另存单张图片或完整结果。

只修改图表样式时，可在概览页“使用已有模型重新绘图”，无需重新训练。更改数据或模型参数后需要完整运行。

## 所有数据设置

- 样本量、阳性比例、数据种子。
- 特征的数量、顺序、名称与类型；可添加或删除连续/二分类特征，并通过上移、下移调整顺序。
- 每个连续特征阳性/阴性组各自的均值、标准差、clip 下限、clip 上限。
- 每个连续特征的数值处理方式和小数位数。
- 每个二分类特征的两个数值编码及阳性/阴性组取第二个编码的概率。
- 结局列名、阴性/阳性显示名称；结局固定编码 0/1。
- ID 列名、前缀、补零位数、起始编号。

阳性人数按 `int(样本量 × 阳性比例)` 计算。分布是正态抽样后限幅，不是截断正态分布。向零取整与四舍五入有区别。默认数据值、训练集划分和模型与原 Notebook 保持一致。

## 保存内容

- `parameters.json`：全部参数快照，可重新载入。
- `data.csv` 与 `clinical_prediction_dataset_with_protective.xlsx`：全部模拟数据。
- `analysis_results.xlsx`：数据、系数、测试集预测、分类报告、混淆矩阵。
- `coefficients.csv`、`test_predictions.csv`、`shap_values.csv`、`feature_importance.csv`。
- `figures/`：PNG 预览及选择的 SVG/PDF。每张图可单独开关。
- `metrics.json`、`运行报告.txt`、`color_verification.json`、`versions.json`。

颜色核对比较绘图对象与配置；PNG 同时记录像素证据。透明度、抗锯齿、重叠或不可见元素会影响像素是否命中，不把缺少单个纯色像素直接等同于对象配色错误。

## 开发与构建

### 应用更新

打包后的应用在启动 1.5 秒后及每 6 小时后台检查 GitHub 最新稳定版。所有页面左下角共享当前版本、检查结果和更新操作，不弹更新提示窗。未检查或网络失败时不会显示“已是最新”；失败可点击重试。开发启动不自动联网，可点击“检查更新”手动检查。

发现新版后显示“有新版 Vx.x.x / 立即更新”，点击后在后台下载对应系统和架构的更新包，核对文件大小和 SHA256。Windows 安装版启动安装向导，使用现有安装路径并退出应用；Mac 和 Windows 便携版打开下载好的 ZIP，需要手动替换应用。运行中的数据任务会阻止启动安装，任务完成后点击“安装更新”继续。

版本号位于 `clinical_studio/version.py`，Mac 打包直接读取，Windows `windows_installer.iss` 的 `AppVersion` 需同步。GitHub Release 保留现有 `ResearchDataTools-*` 文件名，并提供 GitHub asset 的 SHA256 digest 或 `SHA256SUMS.txt`。旧版需要手动安装一次带更新功能的版本。

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python prepare_assets.py
python main.py
python -m unittest discover -s tests -v
python -m PyInstaller --noconfirm SHAPStudio.spec
```

打包环境自检：

```sh
dist/SHAP分析工作台.app/Contents/MacOS/SHAP分析工作台 --self-test ./packaged-verification
```

Windows 需要在 Windows 环境独立构建与验证。当前 Mac 包为本地构建、临时签名，没有 Apple 开发者证书签名或公证；没有宣称可直接通过其他电脑的 Gatekeeper 检查。

Windows x64 的 GitHub Actions、便携版和安装程序流程见 [WINDOWS.md](WINDOWS.md)。构建过程会下载并核验固定 SHA256 的开源字体，成品运行时无需联网。

完整安装包界面回归：`QT_QPA_PLATFORM=offscreen dist/SHAP分析工作台.app/Contents/MacOS/SHAP分析工作台 --ui-verify ./ui-evidence`。该流程在后台操作首页、四个模块的 Qt 控件及保存对话框，不控制用户桌面；核对类别 CSV、数值 Excel、Word 导入与 Excel 导出，以及生图模块全部数据、六张图的独立颜色/字体/字号/线宽和另存结果。四模块隔离检查保存为 four_module_verification.json。

中文字体使用系统中可用的字体，并随包附带 Noto Sans CJK SC 作为后备（许可证见 assets/FONT-LICENSE.txt）。不需联网下载字体。

## 分析含义

默认使用模拟数据、一次分层留出划分、L2 正则化逻辑回归、独立背景的 Linear SHAP。SHAP 解释的是 log-odds。默认年龄分布沿用原代码，因此可能出现年龄负系数。模型系数绝对值受量纲影响；本应用没有执行系数显著性检验或置信区间估计。

## 数据工具集

首页的第一个、第二个入口分别打开对应工具：

- **自定义类别数列**：增删数字及其数量，固定各类数量后随机打乱；可选种子，与 HTML 第一个工具使用相同算法，具体排列不与 R 的种子算法兼容。默认 28 个 1、93 个 0，共 121 个。
- **均数 / 标准差模拟数据**：按均数、样本标准差、例数、小数位和可选上下限近似生成，或在完整上下限内均匀随机生成。显示实际统计值与偏差；不保证正态分布。

结果可按每行一个、逗号、空格或 R 向量格式一键复制，也可通过各自的“保存数据”按钮导出 CSV 或 Excel。数值工具可选随机种子。参数与结果在工具切换及载入 SHAP 配置时保留。工具参数独立于 SHAP 分析配置，分析配置文件不保存这些工具的参数和结果。数值生成在后台运行，未完成时不允许关闭应用。


### Word 批量模拟数据

首页第三个入口“Word 一键生成 Excel”支持导入 `.docx` 的汇总表，按 Word 中的顺序将合并表头展开为“前-指标／后-指标”。识别对照组、中药组的例数和均数±标准差，忽略 t、P、Cohen’s d 等检验行。总有效率和复发率可从“人数（百分比）”单元格读取。无效或缺失统计值在表格标红，并在生成前要求补全；旧版 `.doc` 需另存为 `.docx`。

1. 导入 Word，核对识别报告及指标表。表头、均数、标准差、小数位、上下限、奇偶限制均可修改；可添加／删除指标（每个指标都需两组）。上下限留空表示不限制对应边界。
2. 在第三工具主界面配置每组例数、性别和病情程度比例、可增删的年龄／病程区间及比例、病变范围、有效比例和复发比例。两组可共用或分别配置基本资料，有效/复发比例独立设置。默认导入保留用户人数与比例，采用Word中的值需要明确勾选。基本资料初始值只是示例，不从正文推断。相邻区间如10–20、20–30允许共用边界，边界归入后一段；最后区间包含上界。病变范围可留空、自定义分类或数值区间。
3. 按最大余数法将比例分配为整数人数，再随机打乱；复发分母可选全组或有效者。固定种子和相同配置可重复生成。数字指标沿用第二工具生成函数，并在不违反边界的前提下校正小数数据的均数/样本标准差，导出实际偏差核对。
4. 后台生成，可取消。预览前 200 行；复制／导出包含全部数据。导出含“模拟病例数据”“统计核对”“生成配置”三个工作表，固定前七列为编号、分组、性别、年龄、病程、病情程度、病变范围，指标列之后为总有效率、复发率（逐病例填写有效／无效、复发／未复发）。
5. 可单独保存／载入此工具的 JSON 配置。导出使用生成时的配置快照，不会把后续改动误写为已生成数据的参数。

**这是基于汇总统计的模拟数据，不是原始病例还原。** 数值指标独立近似匹配目标样本均数／标准差，不保证正态分布、前后配对相关性或重现原文 P 值。核对表同时列出实际值和目标偏差；比例因人数取整可能略有变化。该功能不依赖 Word 或 Excel 桌面程序，不修改导入文件，直接使用 Python 标准库读取 OOXML，导出使用现有 openpyxl，无新增依赖。
